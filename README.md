# 계산기 (Calculator)

사칙연산 우선순위를 지키는 웹 계산기입니다. 설치나 빌드 없이 `index.html`만 열면 바로 동작합니다.

**[▶ 바로 써 보기](https://hongsunsik.github.io/calculator/)**

## 주요 기능

- 사칙연산(`+ − × ÷`)과 **연산 우선순위** 처리 (`2+3×4 = 14`)
- `AC`(전체 삭제), `⌫`(한 글자 삭제), `±`(부호 전환), `%`(퍼센트)
- 소수점 입력, 천 단위 쉼표 표시 (`1,234,567.89`)
- 마우스 클릭과 **키보드 입력** 모두 지원 (숫자, `+ - * /`, `Enter`, `Backspace`, `Esc`)
- 잘못된 수식, 0으로 나누기, 너무 큰 숫자에 대한 오류 메시지
- 숫자 길이에 따라 화면 글자 크기 자동 조절

## 사용한 기술

- HTML, CSS, JavaScript (라이브러리·프레임워크 없이 순수 코드)
- 글꼴: [Pretendard](https://github.com/orioncactus/pretendard) (CDN)

2. `index.html`을 브라우저에서 엽니다.

## 구현 포인트

- **`eval`을 쓰지 않았습니다.** 수식 문자열을 직접 `eval`로 실행하면 위험하고 예측하기 어렵기 때문에, 재귀 하강 파서(`evaluate()`)로 곱셈·나눗셈을 덧셈·뺄셈보다 먼저 계산하도록 구현했습니다.
- **소수 계산 오차를 처리했습니다.** 자바스크립트에서 `0.1 + 0.2`는 `0.30000000000000004`가 되므로, `toPlain()`에서 정밀도를 12자리로 맞춰 `0.3`으로 표시합니다.
- **계산 로직과 화면 코드를 분리했습니다.** `calc.js`는 화면과 무관한 순수 함수만 담고, `app.js`가 화면 갱신과 입력 처리를 맡습니다. 덕분에 `calc.js`는 Node.js에서 화면 없이 따로 테스트할 수 있습니다.
- **연산자 입력을 자연스럽게 다뤘습니다.** 연산자를 연달아 누르면 마지막 연산자로 교체하고, `5×-3`처럼 곱셈·나눗셈 뒤의 음수는 허용합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `calc.js` | 계산 로직 (파서, 입력 처리, 표시 형식) |
| `app.js` | 버튼·키보드 입력과 화면 갱신 |
